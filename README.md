# Deckrinth

A turn-based isometric roguelite deckbuilder developed in Godot 4 using C#. This project represents the software artifact for my Bachelor's Thesis.

## Features
* **Isometric Grid System**: Custom pathfinding and movement logic.
* **Dynamic Deckbuilding**: Acquisition and transformation of cards during the run.
* **State Machine Architecture**: Clean separation of game phases (Player Turn, Enemy AI, Chest Looting).
* **Meta-Progression**: Persistent save data for unlocked cards and enemies.

## Technologies Used
* Engine: Godot 4.x
* Language: C# (.NET)
* Architecture: Object-Oriented Programming, Service-based architecture

## Setup Instructions
1. Clone the repository: `git clone https://github.com/your-username/Deckrinth.git`
2. Open the project in Godot 4.
3. Build the .NET solution before running.
